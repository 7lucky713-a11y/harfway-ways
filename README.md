# HARF-WAY WAYS

GitHub is the source of truth for the WAYS public frontend.

- `main`: Preview / development baseline
- `production`: Production release branch

Release flow: edit → Preview → approval → Production.

## Archive Salvager

The Archive Salvager Preview extracts article copy from readable text blocks (`p`, headings, lists, blockquotes) instead of flattening the whole rendered HTML. Images and game/store hints are collected separately.
